# LEDGE VR — pastel parkour, two platforms, one custom engine

MoonyDev's LEDGE is a Gorilla-Tag-style grab-and-fling parkour game built on a
fully custom native engine (no Unity, no Unreal): C++17, OpenXR + OpenGL ES 3.2
toon pipeline on Quest, EGL touch port on Android phones, and an iOS port
(Xcode project in `ledgevr-ios/`) sharing the same game core.

## Repo layout

| Path | What it is |
| --- | --- |
| `ledgevr/native/` | Shared engine + game: renderer, world/physics, Photon realtime + voice, PlayFab, saves, editor |
| `ledgevr/app/` | Android VR app: manifest, Java bridges (WsBridge/HttpBridge/AudioBridge), assets (music/sfx/textures) |
| `ledgevr/app_mobile/` | Android touch app manifest + overrides |
| `ledgevr/vendor/imgui/` | Dear ImGui 1.91.8 vendored |
| `scripts/` | Build scripts (Android), asset generators (music synth, texture pack), PNG decoder host test |
| `ledgevr-ios/` | iOS port: platform shims, Xcode project, build guide |

## Android builds

```bash
# needs NDK r26d + build-tools r34 under toolchain/ (paths at top of scripts)
bash scripts/build_ledgevr.sh          # -> download/LEDGEVR_v1.1_arm64.apk
bash scripts/build_ledgemobile.sh      # -> download/LEDGEVR_v1.1_mobile_arm64.apk
```

Assets (45 MB) are generated by `scripts/gen_audio.py` (numpy synth, ffmpeg
vorbis) and `scripts/gen_textures.py` (PIL, seamless 2048px) — committed in
`ledgevr/app/assets/` so builds work out of the box.

A missing keystore auto-generates a dev one (`ledgevr.keystore` is gitignored —
bring your own for release signing).

## iOS build

See `ledgevr-ios/IOS_BUILD.md`. One-time Mac + Xcode + Apple ID, then
`xcodebuild` or open `LEDGEVR.xcodeproj`. The IPA/APK binaries are release
artifacts — build them locally rather than committing them here.
